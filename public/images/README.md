# Place Images Here

Please download the HSBC logo image and place it here with the following names:

- `hsbc-logo.png` - For the header logo
- `hsbc-bg.png` or `hsbc-bg.jpg` - For the background (can be the same image)

You can download the HSBC logo from:

- Official HSBC website
- Logo repositories like Wikimedia Commons
- Search "HSBC logo PNG transparent" for a logo with transparent background
